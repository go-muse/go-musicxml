# Security policy

## Supported versions

The latest patch release in the `v0.1.x` line receives security fixes.
Pre-release snapshots and older patch releases are not supported.

## Reporting a vulnerability

Please use
[GitHub private vulnerability reporting](https://github.com/go-muse/go-musicxml/security/advisories/new).
Do not open a public issue for a vulnerability that has not been fixed.

Include the affected API, a minimal reproducer or malformed input when
possible, the expected impact, and any suggested mitigation. Reports will be
acknowledged through the private advisory.
