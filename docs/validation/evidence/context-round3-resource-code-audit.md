This review makes no production edits or GitHub writes. The final measured production fingerprint is in report.json; the inspected integrated code is checked against that fingerprint and against the committed production tree.

- Reader fallback roles reserve per-match backing as scratch, retain cache overhead only after scanning and sorting succeed, then transfer admitted backing to session retention at the cache commit. A later returned-role traversal can still be interrupted; that committed cache legitimately remains owned. A fresh reader cannot borrow that cache and owns its own successful cache. Failed pre-commit builds must release all scratch even with repeated attempts on the same Account. Owner tables similarly keep their table reservation as scratch through the second scan and sort, then transfer exactly once with no fallible construction remaining.
- Layout staff selection key/order maps are call scratch. The unknown-part local bucket map and bucket storage are also call scratch, retained through all owned publications and then released on success, quota refusal, and cancellation. Known-part buckets are persistent state and remain session-retained; treating those as scratch would undercount live data. Decimal staff selector strings are admitted before materialization using a finite conservative integer-byte bound, with checked size arithmetic.
- The tied-identity ambiguity preflight scans each already keyed run once. Its per-anchor map and base map allowance are admitted before writes; a defer releases them at every exit. No output owns this map. A same-note interpretation ambiguity is reported across that exact identity run, so the charged work and outcome are order independent. This is conservative evidence, not a new invalidity rule.

The existing domain index is borrowed; no copy is introduced. Identity strings escaping into retained endpoints receive separate session retention before the scratch index is released. The part and unknown-domain gaps are merged into completeness before the tied stub pass.
