# Auxiliary container and sounds source scope

Baseline: `3d3d936fa4ba250083da03651cbfb4bbbe936914` (tree
`af0c381754eb49a5f645fe9a08483c4c96d21f51`). This is the source-assembly
prerequisite of batch 8, not acceptance of the entire package/link increment or
transitive MusicXML normative closure. Original planning statuses are unchanged.

## Selected source scope

`ProfileSourceContainer` and `ProfileSourceSounds` run the existing six sealed XSD
operations (binding, declaration, attributes, scalar, content and document
identity) on generated `container.xsd` and `sounds.xsd` metadata. Their catalog is
separate from all eight earlier source/model catalogs. All declarations, types,
attribute uses and homonyms retain `AssemblyContainer` or `AssemblySounds`.
No generated Go Document roots or permissive decode changes are introduced.

The [36-record map](auxiliary-source-ownership.json) retains the exact 11
container and 25 sounds research IDs, source locators and parameters, with
concrete five-axis fixture references and explicit target limitations. These are
research records composed through six XSD operation families, not 36 new runtime
predicates or a global coverage denominator. Original transitive language
contracts are reused through the existing shared XSD kernel; no new XSD dialect
or ad hoc auxiliary XML parser is introduced.

The pinned container schema is authoritative despite its copied sounds-file
annotation/schema-locator text. Those editorial mistakes do not alter the root,
create a new rejection rule, or cause schema retrieval. This source profile does
not inspect archive entries, mimetype bytes, rootfile targets or package roles.
All such package obligations remain independently selected work.

## Directional sounds evidence

A separate sealed sounds context plan binds exact declaration uses. `sound`
projects reverse library-to-MusicXML primary preference; `any`, `solo` and
`ensemble` each project forward MusicXML-to-library preference. Results keep
source order and independent subjects, including repeated equal library strings,
multiple explicit primary=yes values and empty/absent mapping lists. No mapping
is automatically selected or reduced to a dictionary.

`Primary` keeps explicit yes/no distinct from absence, Unknown, Unsupported and
Invalid. `LibraryID` is `xs:string`, including whitespace and the empty string.
Ensemble `Number` is `xs:NMTOKEN`, including nonnumeric strings and colons; it is
not a QName or a numeric ensemble-size requirement. SoundID is a lexical/value
projection of the XSD ID attribute; document uniqueness is assessed separately
and must not be bypassed by treating a projection as a conformance certificate.
`Content` keeps the owning sound's exact grammar and enumeration independent of
otherwise known fields. Unwitnessed child declarations are not guessed by name.

Public records are caller-owned snapshots. The shared context publisher checks
its closed payload union, admits context facts and retained deep copies, charges
work before traversing/copying strings and causes, and publishes atomically.
Cancellation and resource limits preserve completed prefixes and independent
failures while preventing acceptance. Cleanup releases internal live storage;
cumulative counters are not refunded. No callback, resolver, network authority,
application-library lookup, renderer or playback behavior is added.

## Verification and precise unavailable branches

- `TestAuxiliarySourceAssemblies` exercises original bytes across nullable and
  repeated sound branches, ordering, required/unknown/qualified attributes,
  whitespace/value domains, missing/invalid/duplicate IDs, actual-type selection,
  nonnillability, foreign children, assembly collisions and profile admission.
- `TestAuxiliarySourceAgainstOriginalSchema` gives those exact same bytes to real
  xmllint using the pinned local schemas and catalog. No model encode/roundtrip is
  used as an oracle. Wrong/foreign roots are schema-invalid to xmllint but are
  explicitly unsupported profile admission in this API; neither is accepted.
- `TestAuxiliaryGeneratedSchemaMetadata` checks root abstract/nil/block/final and
  exact assembly identities. The pinned assemblies contain no derived root
  candidate or substitution-group member, so root extension/substitution/final
  rejection cannot be instantiated using only these unchanged schemas. Their
  metadata is asserted; the already existing generic XSI derivation suite owns
  executable dynamic derivation semantics. This is an explicit fixture limit,
  not an omitted or relaxed block/final rule.
- Directional source tests assert all four roles, repeated alternatives,
  independent causes and current-model/Decode exclusions. Core missing-fact
  tests cover Unknown, Unsupported and Invalid scalar/enumeration evidence and
  exact cross-assembly declaration mismatch without changing the production
  source parser to manufacture partial facts.
- Source unread external DTD controls remain incomplete rather than accepted or
  normatively invalid. No external DTD/schema retrieval is performed. There are
  no direct current-model auxiliary roots; package consumer availability is a
  separate later integration obligation, not implicitly tested by source tests.
- Exact and one-under input, context-fact, work and retained-byte limits are
  exercised. Core provider and publication tests cancel at every observed poll,
  preserve only complete projections, verify owned causal graphs and confirm
  zero live buffered bytes after cleanup. Source readers are never closed.
- `TestAuxiliaryFrozenEightProfiles` compares the canonical baseline's complete
  eight minimal-Opus reports and profile metadata, including digests and counts.

The initial matrix was run before production edits on the canonical baseline;
it failed with unknown explicit source profile for each case. The later same
matrix passes with real original-byte xmllint controls. Additional final checks
and their exact command outcomes are recorded in the task handoff. Full batch-8
integration, exact-head cross-platform CI and global readiness remain the lead's
independent gates.
