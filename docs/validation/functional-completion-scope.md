# Combined functional contribution and retained boundaries

This is a contribution audit for current MusicXML 4.0 document validation:
XML syntax, fixed-schema/source facts and encoded musical semantics. It is not a
claim to validate an unobserved desired score, renderer output or every transitive
external standard. Existing original planning records remain unchanged.

The [machine-readable crosswalk](functional-completion-crosswalk.json) preserves
50 original external/package/link IDs with their 44 attached test contracts and a
separate 59-ID musical supplement. It retains the original 95 engineering
requirements/tests as the unchanged overall denominator; preserving that count is
not a fresh individual certification of all 95. The crosswalk names source-record
pointers, current code, executable test routes and explicit remaining boundaries.
Test routes identify current functions/files, not historical line coordinates or
proof that every original planned case was executed. Overlapping IDs/families do
not add independent requirement counts.

## Implemented functional contributions

- Actually read internal declaration domains for reached ENTITY/ENTITIES values,
  physical/effective attribute separation, source-origin snapshot ownership and
  per-adoption document/location remapping.
- Exact DTD/dictionary source and package composition, including effective
  Container metadata without reconstructing original bytes from current models.
- MIME base identity with distinct parameters and duplicate checks; the
  source-contextual local-header mimetype-extra predicate, independently of
  central framing uncertainty; global matching-descendant attachment ordinal.
- Truthful bounded scalar/wildcard corrections, preserving independent failures
  instead of converting unavailable prerequisites to definitive success.
- Effective first-bound DTD and XSD identity join, complete element-child order,
  registered XML Framework/shorthand/element addressing and unchanged direct
  compressed-target indirection boundaries.
- Numeral harmony advice scoped to its own kind, direction-wrapper formatting
  carry, independent barline endpoint proofs and a closed singleton-repeat
  counterexample theorem that preserves established positive proofs.
- Explicit source/current-model/graph/raw-MXL/current-MXL semantic compositions
  through existing entry points and finite shared accounts.

The affirmative IPA representation consumer is still in implementation at this
checkpoint. Its separate current-symbol/Unicode13 witness must be verified before
that row can become implemented. Legacy positive IPA data remains explicitly
partial. Neither lookup absence nor unsupported historical spellings becomes a
normative negative.

## Corrected overgeneralizations

The format permits unrestricted figure-number style-text. The built-in invented
numeric requirement was removed; the old explicitly selected custom constructor
is retained and deprecated. Original IDs and historical receipts remain visible.

Desired written-versus-concert pitch intentions cannot be recovered from a file.
The provisional optional authority API was reverted before publication. Encoded
alter/transpose checks remain. Unselected external intent does not make a report
incomplete. Similarly, a generic XSD schema-default election was reverted after
six-schema reachability found no applicable MusicXML4 dependency; this is not a
claim that the historical standards clarification was revoked.

Generic inherited xml:base/xml:id, arbitrary XPath and all historical phonetic
aliases were not made mandatory merely by broad research labels. Source-backed
reachable fragment and current-symbol obligations retain their actual scope.
No dictionary storage/version redesign, DDD redesign or performance tuning is
part of this functional contribution.

## Boundaries that remain explicit

Full arbitrary ZIP/JAR/DEFLATE certification, unselected legacy compression and
original-source reconstruction are not promised. Ordinary reviewed package
framing is distinct from transport refusal and technical payload errors.
Compressed archive-to-primary substitution remains unresolved for the original
outer target obligation even when its inner XML is inspected successfully.
Missing instance association/role authority remains unavailable without guesses
from names, IDs or filenames.

General repeat/playback equivalence and every possible barline endpoint are not
proved by the new closed-domain algorithms. Unsettled omitted-dot and equal-time
interpretations retain precise unavailable evidence rather than invented grammar.
The individual source disposition pages and crosswalk preserve these boundaries;
a missing mandatory algorithm is not called complete solely because it returns
Unknown.
